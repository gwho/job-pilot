# JobPilot

JobPilot is a job hunting assistant context. This glossary pins down the product language used when discussing job discovery, matching, and application preparation.

## Language

**Saved job history**:
All jobs saved for the current user across all job discovery runs. This is the canonical meaning of the job list on the Find Jobs page.
_Avoid_: All jobs, historical jobs, full list

**Search run results**:
The jobs returned and saved by one execution of the job discovery agent.
_Avoid_: Search results, latest jobs

**Current job list view**:
The filtered, sorted, and paginated projection of the user's saved job history currently shown on the Find Jobs page.
_Avoid_: Table state, visible jobs

**Unscored job**:
A saved job whose match score is unknown because matching has not produced a real score for it. It is not a low match and should only appear in complete views such as All Matches.
_Avoid_: Low match, bad match, zero-score job
