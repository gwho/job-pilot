Server data flow

export const dynamic = "force-dynamic";   // required on per-user auth-gated pages

export default async function Page({
  params,
}: {
  params: Promise<{ id: string }>;         // Next.js 16: Promise, not plain object
}) {
  const { id } = await params;             // must await — TypeScript won't catch missing await
  const insforge = await createInsforgeServer();

  const { data: authData } = await insforge.auth.getCurrentUser();
  if (!authData?.user) redirect("/login");

  const { data: job, error } = await insforge.database
    .from("jobs")
    .select("*")
    .eq("id", id)                          // filter by UUID
    .eq("user_id", authData.user.id)       // BOTH filters required — security boundary
    .single();

  if (error || !job) notFound();           // 404 not 403 — never reveal existence of other users' records
  const typedJob = job as Job;             // safe: select("*") matches Job interface
}

  {/* other cells — covered by ::after */}

Why (not onClick)

  • Real <a> → right-click works
  • Middle-click → new tab
  • Hover → URL in status bar
  • Screen reader → announced as link
  • No "use client" needed
  • after:z-1 → wins stacking order over other cell content

Plan review checklist print

Route & data

  • Server Component (no "use client")
  • force-dynamic present
  • await params (not sync read)
  • Two-filter query: id + user_id
  • notFound() for missing/unauthorised
  • redirect("/login") if no session

Design system

  • Token classes only — no raw Tailwind colors
  • Card radii match registry
  • No hex values

Navigation

  • Stretched <Link> (not onClick)
  • <tr> has relative
  • after:absolute after:inset-0 after:content-[''] after:z-1
  • aria-label present
  • External links: target="_blank" rel="noopener noreferrer"

Null states

  • job_type: null → "—" not "Full-time"
  • salary: null → "—"
  • match_score: null → hide badge
  • match_reason: null → hide card
  • Empty skills → message
  • Apply URL null → disabled button
  • about_role: null → message
  • Scraped text → whitespace-pre-line

Architecture

  • Components path from architecture.md
  • No unnecessary client components
  • Scope respected (no unplanned agents/mutations/events)
  • Future change boundaries identified

Verification

  • npm run build + npm run test:run
  • Smoke test: null-field cases
  • Smoke test: right-click row
  • Smoke test: Apply goes to external_apply_url

Key helpers to know

formatJobType (JobInfo.tsx)

function formatJobType(t: string | null) {
  if (t === "fulltime") return "Full-time";
  if (t === "parttime") return "Part-time";
  if (t === "contract") return "Contract";
  return "—"; // null → "—", never a default
}

matchBadgeClasses (JobInfo.tsx)

function matchBadgeClasses(score: number) {
  if (score >= 70)
    return "bg-success-lightest text-success-dark";
  if (score >= 50)
    return "bg-warning-light text-warning";
  return "bg-surface-tertiary text-text-muted";
}
// returns FULL class strings for Tailwind scanner
