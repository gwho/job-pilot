Feature 11 URL State Cheat Sheet

Use this when deciding where state belongs in the Find Jobs flow.

URL View State

q, match, sort, and page.

These describe how saved job history is being viewed. They survive refresh, sharing, and back navigation.

Local Action Inputs

jobTitle and location.

These drive the discovery action. They stay local because loading a URL must not re-run the actor.

Local Display State

filterTextDraft.

This controls the input while typing. It debounces into URL q after 300ms.

Local Data Cache

jobs.

Seeded from server initialJobs, then merged with API search results using functional setJobs.

Rules

Use router.replace() for refinements of the same screen.

Use router.push() for navigation to a different page, such as a job detail route.

Use != null for match-score presence checks so both null and undefined mean unscored.

Use functional state updates when merging new jobs into existing jobs.
