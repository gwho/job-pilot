router.replace() vs router.push()

router.replace(url)

Overwrites current history entry. Back button goes to what was there before this page — not through intermediate filter states.

Use for: match, sort, page, text filter (q) — all refinements of the same view.

router.push(url)

Adds a new history entry. Back button returns to this page.

Use for: clicking a job row (Feature 12) — navigating to a genuinely different page.

Two-effect guard pattern

FindJobsClient.tsx
const [filterTextDraft, setFilterTextDraft] = useState(q);

// Effect 1: URL → draft (back-nav sync)
useEffect(() => {
  // eslint-disable-next-line react-hooks/set-state-in-effect
  setFilterTextDraft(q);
}, [q]);

// Effect 2: draft → URL (debounce typing)
useEffect(() => {
  if (filterTextDraft === q) return; // ← GUARD: prevents replace loop
  const timeout = window.setTimeout(() => {
    replaceViewState({ q: filterTextDraft, page: 1 });
  }, 300);
  return () => window.clearTimeout(timeout); // ← cleanup cancels timer
}, [filterTextDraft]);

Without the guard: back-nav → Effect 1 sets draft → Effect 2 fires → replaceViewState → URL changes → Effect 1 fires → infinite loop. The guard short-circuits Effect 2 when draft already equals URL.

Functional merge — find-jobs-utils.ts

FindJobsClient.tsx — handleSearch
setJobs((currentJobs) => mergeJobsById(currentJobs, data.jobs as Job[]));
lib/find-jobs-utils.ts
export function mergeJobsById<T extends { id: string }>(current, incoming): T[] {
  const merged = new Map(current.map((job) => [job.id, job]));
  for (const job of incoming) merged.set(job.id, job); // newer wins
  return [...merged.values()];
}

Always use the functional form setJobs(prev => ...) for merges. The closure form captures a stale jobs array if two searches overlap.

Null score rules

Never use ?? 0. It puts unscored jobs in Low Match where they do not belong. Use != null (loose) to catch both null and undefined.

Rules to carry forward

🔗If it answers "what am I looking at?" → URL. If it answers "what happens when I click?" → useState.
🔁Filter/sort/page changes → router.replace(). Row-click navigation → router.push().
⏱️Text input: filterTextDraft controls the visible input. URL q drives the filter. 300ms debounce between them. Guard prevents loop.
🗂️After search: functional setJobs(prev => mergeJobsById(prev, incoming)). Never setJobs(data.jobs).
❓Unscored jobs (match_score == null) are not 0%. They only appear in All Matches. Never use ?? 0 for scores.
📄One owner for PAGE_SIZE: the component that slices defines it; other components receive it as a prop.
🧪Pure functions (parse helpers, merge, page numbers) live in lib/find-jobs-utils.ts so they can be tested in isolation.
