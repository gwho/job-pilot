# Mission: Learn JobPilot by Reading Its Real Code

## Why
You want to understand JobPilot well enough to build future features with the repo's actual architecture, not generic Next.js examples. The goal is to turn each generated tutorial and session doc into practical implementation skill.

## Success looks like
- Explain why a JobPilot feature uses a specific state, routing, data, or UI pattern.
- Trace a user action through the real files that implement it.
- Modify a nearby feature without breaking the project conventions.
- Ask sharper questions of Codex skills like `/architect`, `/tdd`, `/tutorial`, and `/teach`.

## Constraints
- Lessons must be grounded in this codebase's real files.
- Keep lessons short enough to finish in one sitting.
- Prefer retrieval practice and small code-tracing tasks over passive reading.

## Out of scope
- General Next.js theory that does not explain a JobPilot implementation decision.
- Rewriting features during teaching sessions unless explicitly requested.
